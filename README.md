# BizAccess

# Overview

BizAccess is a simple Business User Management System built with TypeScript. The software is designed to demonstrate how TypeScript can be used to manage business users through a structured application. It allows users to be added, searched, updated, and removed while demonstrating important programming concepts such as classes, lists, functions, recursion, asynchronous functions, and exception handling.

The purpose of creating BizAccess is to strengthen my understanding of TypeScript syntax and programming concepts by applying them to a practical software project. I want to improve my ability to organize code, work with objects and data collections, handle errors, and create functions that solve real-world problems.

The application manages basic business user information, including user ID, name, email, and role.

BizAccess Software Demo Video (https://youtu.be/ugDoKZiKtfQ)

# Development Environment

I developed this software using Visual Studio Code as my code editor and the integrated terminal to compile and run the application. I used Node.js to execute the compiled JavaScript and the TypeScript compiler (`tsc`) to convert the TypeScript code into JavaScript.

The programming language used for this project is TypeScript. The project uses TypeScript's built-in features, including classes, lists, object Manipulation, interfaces, arrays, functions, recursion, asynchronous functions, and exception handling. Node.js and the `@types/node` package are used to support Node.js functionality.
